# Mosaic
Work in progress UI component system for Roblox.

## Useful utilities.
[`ColorSpace`](./utils/colorSpace): Designed as a replacement to roblox's `Color3`. Supports the `Srgb`,`LinearRgb`,`Xyz`,`Oklab`, and `Oklch` color spaces. Also supports converting to and from roblox's `Color3`. Has utilities for stringification and contrast checking.

[`FusionUtils`](./utils/fusionUtils): A collection of useful utilities for Fusion.
